# slate

A calorie journal for urban Indians. You type what you ate on a line, and a number appears next
to it. Expo + Supabase, iOS only for v1.

Start with [`CLAUDE.md`](CLAUDE.md), then [`MASTER.md`](MASTER.md), then
[`HANDOVER.md`](HANDOVER.md) for where things stand. **A push to `main` deploys to production.**
